1. Bib key `Lin2022PhishSheep` — id `11b8be0c43685cdd` — Lin et al., "Phish in Sheep's Clothing: Exploring the Authentication Pitfalls of Browser Fingerprinting", USENIX Security 2022.

   Check: how fingerprint replication gets past risk-based authentication and two-factor authentication, on which and how many services, under what conditions (what the attacker must already hold, e.g. the password), whether it was run against real services, and how common the needed fingerprinting is among real phishing sites.
2. Bib key `Holthouse2025TwentyThreeAndMe` — id `6f67f4463309e31c` — Holthouse, Owens and Bhunia, "The 23andMe Data Breach: Analyzing Credential Stuffing Attacks, Security Vulnerabilities, and Mitigation Strategies", arXiv 2502.04303.
   Report sentence (threat R1): "A password chosen and reused by the user falls to credential stuffing; one analysed breach began with about 14 000 accounts taken over in that way".
   Check: where the 14,000 figure comes from (the paper's own data, or a company statement or press it cites — name the cited source), what the paper's own method is (is it an analysis of public reports?), and what exactly it says about multi-factor authentication being absent or optional at the time.
3. Bib key `Spooren2015Fingerprinting` — id `ea9ac25b8ead8b73` — Spooren, Preuveneers and Joosen, "Mobile Device Fingerprinting Considered Harmful for Risk-based Authentication", EuroSec 2015.
   Report sentence: "on mobile devices those fingerprints are too alike to tell users apart".
   Check: the data behind it (how many devices or users, which attributes), the measure used, and whether "too alike to tell users apart" overstates what the paper shows (it may say less reliable, more predictable or spoofable rather than indistinguishable).
4. Bib key `NIST2016PIVPrivileged` — id `9bc27c3a2430ba53` — NIST Cybersecurity White Paper "Best Practices for Privileged User PIV Authentication" (2016).
